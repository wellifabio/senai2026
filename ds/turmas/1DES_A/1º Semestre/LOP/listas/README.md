# Listas de exercícios de LOP

Crie uma pasta e junte as listas de exercícios de LOP (Linguagem de Programação) nesta pasta.
- Lista01 - da aula 03 - Aritimeticos
- Lista02 - da aula 06 - Condicionais
- Lista03 - da aula 07 - Laços de Repetição
- Lista04 - da aula 12 - Vetores e Matrizes

## Instruções
Envie para o github em um repositório chamado `listas-lop` e compartilhe o link do repositório com o professor.
## Readme
Crie um arquivo README.md com as instruções de como executar os exercícios e o que cada lista contém.
- Criem um arquivo .gitignore para ignorar arquivos *.exe
- Envie o link do repositório para o professor através do [formulário de envio de atividades](https://forms.gle/k2y8A8gBeo1yjRHbA).
