# Aula04 - Portfolio

Um portfólio é uma coleção organizada de trabalhos, projetos ou amostras que apresenta de forma prática as habilidades, experiências e realizações de uma pessoa ou empresa.

## Exemplos
- Portfolio da [Turma Programando com ChatGPT 2026](https://wellifabio.github.io/senai_portfolio_fic_chatgpt_2026/)
- Portfolio do [professor Robson](https://robsonbsouzaa.github.io/)
- Portfolio do [professor Wellington](https://wellifabio.github.io/new/)

## Atividade
Atualize seu portfolio, incluindo os projetos:
- Front-end hospedados no GithubPages,
- Repositórios de projetos Full-stack (Com prints das telas e tutorial para testar),
- Repositórios de projetos Mobile (Comp prints das telas, passos para testar e .APK)
