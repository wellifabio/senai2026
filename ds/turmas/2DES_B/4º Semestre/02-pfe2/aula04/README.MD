# Aula 04 - Expo e React

Nesta aula conversamos um pouco sobre criação de aplicativos com Expo e React


## Como iniciar um projeto

Acesse o site: https://docs.expo.dev/

No site copie o comando 

```bash
npx create-expo-app@latest
```

Após rodar o codigo siga o processo de criação com nome do projeto e selecione a ultima versão do SDK (latest SDK)

Apos projeto criado, acesse a pasta e abra com o VSCode

para rodar o projeto na web basta dar o comando 

```bash
npm run web
```
