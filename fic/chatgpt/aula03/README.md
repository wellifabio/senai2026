## Atividade prática: Portifólio
### Contextualização:
O portifólio é uma ferramenta importante para apresentar suas habilidades e projetos para futuros empregadores, clientes ou parceiros. Ele pode ser utilizado para mostrar seus projetos pessoais, trabalhos acadêmicos, contribuições para projetos de código aberto, entre outros.

### Desafio:
- Crie um portifólio online utilizando uma plataforma de sua escolha, como GitHub Pages, WordPress, Wix, entre outros.
- O portifólio deve conter uma seção de projetos, onde você deve incluir pelo menos 2 projetos que você desenvolveu, seja para fins acadêmicos, pessoais ou profissionais. Para cada projeto, inclua uma descrição do projeto, as tecnologias utilizadas e um link para o código-fonte (se disponível).
- O portifólio deve conter uma seção de habilidades, onde você deve listar as tecnologias que você domina, como linguagens de programação, bibliotecas, frameworks, entre outros.

### Entrega:
- O portifólio deve ser enviado para o github, e deixado como público, para que o instrutor e outros colegas possam acessar e aprender com o seu código.
- Habilite o GitHub Pages para o seu repositório, para que o portifólio possa ser acessado através de um link personalizado.

## Produtividade:
O programador a era da IA Generativa deve ser capaz de utilizar as ferramentas de IA para aumentar sua produtividade, seja para realizar pesquisas, corrigir bugs, refatorar códigos, aprender novas tecnologias, entre outros.

## Pesquisas:
- IAs como Copilot, ChatGPT e Bard podem ser utilizadas para realizar pesquisas de forma mais eficiente, encontrando informações relevantes de forma rápida e precisa.

## Correção de Bugs:
- IAs podem ser utilizadas para identificar e corrigir erros em códigos, analisando o código e sugerindo correções de forma automática.

## Refatoração:
- IAs podem ser utilizadas para refatorar códigos, melhorando a legibilidade, desempenho e manutenção do código.

## Aprendizado de tecnologias:
- IAs podem ser utilizadas para aprender novas tecnologias, como linguagens de programação, bibliotecas, frameworks e documentações no geral, fornecendo explicações, exemplos e guias de estudo personalizados.

## Guia de estudos:
- IAs podem ser utilizadas para criar guias de estudo personalizados, com base nas necessidades e objetivos do usuário, fornecendo recursos, exercícios e avaliações para ajudar no aprendizado.
